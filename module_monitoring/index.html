loading /runs…

one recorded run of the whole chain, as its stages left it. The stage columns come from the kernel's accounting of the process that ran the stage — exact CPU and peak resident set from wait4, byte counts from /proc/<pid>/io — so the page cache the container is charged is never counted against a stage. The columns marked container describe the whole container over the same window, the network among them: no per-process byte counter exists, so network is reported container-wide and never attributed to a stage.
