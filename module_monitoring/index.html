Canonical dataset construction

one section per provider, in the tier order the snapshot publishes. The canonical table names the providers once more, in its share columns — a share of the grid is the one number that is per provider by nature; every other column of it describes one market object and asks about no source. A marked column is an invariant, whose only correct value is zero; every other number is an observation, which a change of provider is expected to move. A canonical minute is one venue's whole candle copied verbatim — Binance where it traded, Bybit where only Bybit did, an explicitly flagged forward fill where neither printed — and never an average of the two, because an average prints a price no market made.
